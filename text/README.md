# Translating Geographic Labels (`text/`)

Every string a player sees in Geographic Labels is a `LOC_*` tag defined here and looked up by the game at run time,
including the names painted on the map. A translation needs no code change: add the language's files here and
register them in the modinfo.

## Files

| File | Contents |
| --- | --- |
| `en_us/ModText.xml` | The mod's name and description, the Options entries, the mini-map checkbox, the Rename Places window and its Type column, and the frames (`LOC_GEO_LABELS_FRAME_<TYPE>`) that wrap a name with no label of its own (86 tags). |
| `en_us/PlaceText.xml` | Every place name the map can draw (2,623 tags). Generated by `devtools/gen-places.mjs` from the name pools in `ui/geo-labels-toponyms.js`; to change the English, edit the pools and run the script from the mod folder. |

All eleven languages below ship as machine translations (2026-10-01). To correct one, edit its `<Text>`; to change the
English, edit the English and update every language. `node devtools/check-locale.mjs <folder>` checks one folder.

## Place names

Generated names are saved with the game as their pool names ("Sicilia", "Adriatic"), which are the same in every
language, so a game keeps its names when the player switches language and only the text on the map changes. Each pool
name has two tags:

- `LOC_GEO_PLACE_<NAME>`: the name on its own. The National Parks mod names a park after it ("{1_Name} National
  Park"), so it must read as a noun.
- `LOC_GEO_NAME_<TYPE>_<NAME>`: the whole label for one kind of place, worded the way the language names it: "Isle of
  Sicilia", "Mer Adriatique", "シチリア島", "Аденский залив". Where a name already carries its own geographic word
  ("Hindu Kush", "Miyajima"), the label is the name alone.

Names a player types in Rename Places are drawn exactly as typed, in any script the game's fonts cover: Latin with
accents, Cyrillic, kana, kanji, hanzi and Hangul.

## Two file shapes

English uses an `EnglishText` block with `Row`:

```xml
<Database>
    <EnglishText>
        <Row Tag="LOC_GEO_NAME_SEAS_ADRIATIC"><Text>Adriatic Sea</Text></Row>
    </EnglishText>
</Database>
```

Every other language uses a `LocalizedText` block with `Replace` and a `Language` attribute:

```xml
<Database>
    <LocalizedText>
        <Replace Tag="LOC_GEO_NAME_SEAS_ADRIATIC" Language="de_DE"><Text>Adriatisches Meer</Text></Replace>
    </LocalizedText>
</Database>
```

**The `Language` value is not the folder name.** Use these exactly (note `zh_cn` and `zh_hk`):

| Folder | `Language=` | Folder | `Language=` |
| --- | --- | --- | --- |
| `de_de` | `de_DE` | `pl_pl` | `pl_PL` |
| `es_es` | `es_ES` | `pt_br` | `pt_BR` |
| `fr_fr` | `fr_FR` | `ru_ru` | `ru_RU` |
| `it_it` | `it_IT` | `zh_cn` | `zh_Hans_CN` |
| `ja_jp` | `ja_JP` | `ko_kr` | `ko_KR` |
| `zh_hk` | `zh_Hant_HK` | | |

A new language also goes in `devtools/languages.mjs`.

## Registering a language in the modinfo

`ModText.xml` is listed in both action groups (the shell group, for Options in the main menu, and the game group);
`PlaceText.xml` only in the game group. For German, in `geographic-labels.modinfo`:

```xml
<!-- geo-labels-game, under <UpdateText> -->
<Item locale="de_DE">text/de_de/ModText.xml</Item>
<Item locale="de_DE">text/de_de/PlaceText.xml</Item>

<!-- geo-labels-shell, under <UpdateText> -->
<Item locale="de_DE">text/de_de/ModText.xml</Item>
```

## Rules

- **Every tag, in every language.** Each language must hold exactly the English tags. A missing label falls back to
  the language's frame and then to the English, but a missing interface tag shows as the raw `LOC_...` key.
- **Keep the placeholders.** Each frame holds `{1_Name}` once, placed where the language needs it. In practice a frame
  receives the game's own river name at an estuary, in the nominative, so it must not need the name's gender or case.
- **The mod's name.** Polish translates it ("Etykiety geograficzne"), as the Demographics mod's Polish does; the
  other languages keep "Geographic Labels", as the National Parks mod's text calls it.
- **Polish is its own file.** `pl_pl/ModText.xml` keeps the Demographics layout: a header comment, tab indentation,
  one `<Replace>` per tag over several lines. It uses Polish exonyms wherever Polish has one (Sycylia, Mazury,
  Karkonosze) and Polish quotation marks („…”). Keep that shape and that standard when adding tags.
- **Keep the ★** in `LOC_GEO_LABELS_RENAME_HINT`: it explains the star beside the player's own names.
- **No duplicate tags.** A tag defined twice in one file makes the game drop the whole file.

## Checking a translation

`npm test` (`tests/geo-labels-i18n.test.mjs`) fails when a translation is missing a tag or has an extra one, uses the
wrong `Language`, uses `Row` instead of `Replace`, defines a tag twice, drops a placeholder, or is not registered in
the modinfo. It also checks that the English place text is current with the pools and that every key the mod uses
has English text. To build a `PlaceText.xml` from a table of `TAG<TAB>text` lines, run
`node devtools/tsv-to-xml.mjs <folder> <file.tsv>...`.
